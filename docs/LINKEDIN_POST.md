🚀 I built **ResumeFit**, a free ATS resume checker that runs 100% in your browser.

Most companies use Applicant Tracking Systems to filter resumes before a recruiter ever sees them. As a student, I kept wondering: *"Is my resume even passing the filter for this job?"*

So I built a tool that answers that in under a second.

🔍 **What it does**
✅ Gives an ATS-style match score (0–100) for your resume vs. any job description
✅ Shows which required skills you have and which ones are missing
✅ Pulls out the key words from the job post that your resume doesn't mention
✅ Runs 7 resume health checks (contact links, sections, quantified impact, action verbs, length)
✅ Gives clear, actionable suggestions
🔒 Your resume never leaves your device: no server, no sign-up

🛠️ **Tech:** HTML · CSS · JavaScript · pdf.js · Node test runner · GitHub Actions · GitHub Pages

💡 **What I learned**
• Writing a text-matching engine that handles tricky tokens like C++, C# and Node.js (and doesn't confuse Java with JavaScript!)
• Designing a transparent, weighted scoring system
• Keeping logic pure and testable, with unit tests running in CI on every push
